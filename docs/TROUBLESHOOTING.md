# CoD2 Chat Translator — Troubleshooting

## F9 не открывает исходящий чат

Проверь:

1. В главном окне включён исходящий чат F9.
2. При запуске программы подтверждён UAC.
3. CoD2 Multiplayer запущен.
4. Используется актуальная версия программы.

## Нет входящего перевода

Проверь интернет, настройки перевода и правильность найденной установки CoD2.

Если автоматический поиск не сработал:

Настройки сервера → Указать папку игры

и выбери папку с `CoD2MP_s.exe`.

## Пропал оверлей

Нажми **F8**.

## Куда сохраняются скриншоты F10

%USERPROFILE%\Pictures\CoD2 Chat Translator\Screenshots

## Программа просит права администратора

Начиная с **v1.16.1**, это нормальное поведение.

## Windows error 740 после обновления

Используй **v1.16.1 или новее**.

В v1.16.1 изменён способ запуска с повышенными правами, чтобы старые версии updater могли нормально запускать новую версию программы после обновления.

---

## English

F9 requires outgoing chat to be enabled, CoD2 Multiplayer to be running and the UAC prompt to be accepted.

F8 restores the incoming translation overlay.

F10 screenshots are saved to:

%USERPROFILE%\Pictures\CoD2 Chat Translator\Screenshots

Use **v1.16.1 or newer** if you encounter Windows error 740.

---

## Українська

Для F9 вихідний чат має бути увімкнений, CoD2 Multiplayer запущено, а UAC підтверджено.

F8 повертає оверлей перекладу.

Скріншоти F10 зберігаються тут:

%USERPROFILE%\Pictures\CoD2 Chat Translator\Screenshots

У разі Windows error 740 використовуй **v1.16.1 або новішу версію**.
