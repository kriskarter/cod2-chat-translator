# Asset provenance

This document records the intended origin and use of visual assets in the
CoD2 Chat Translator repository.

## Project branding

The application icon, project logo and README promotional artwork were created
specifically for CoD2 Chat Translator as project branding.

They are not presented as official Activision or Call of Duty artwork.

## Gameplay screenshots

Gameplay screenshots used in the README were captured for demonstration of the
translator during Call of Duty 2 gameplay.

They are included only to demonstrate compatibility, chat translation and the
overlay in use.

## Call of Duty name and marks

The names "Call of Duty 2" and "CoD2" are used only to identify the game with
which the utility is compatible.

CoD2 Chat Translator is an unofficial fan-made utility and is not affiliated
with, sponsored by, or endorsed by Activision.

Call of Duty and related marks belong to their respective owners.

## Future assets

Before adding new promotional artwork, icons or screenshots, their origin
should be known and documented. Assets copied directly from third-party
promotional artwork should not be added unless their use is clearly permitted.
