# CoD2 Smart Translation Engine V1 — технический паспорт

Статус: **v1.18.0 release candidate**. По правилам
[RELEASE_PROCESS.md](RELEASE_PROCESS.md) большой релиз обязан пройти ручную
проверку на Windows и в реальной игре до merge/tag/Release.

## Что реализовано

- F8 и F9 вызывают единый интерфейс SmartTranslationEngine.translate(request, provider, legacy_transform).
- Google Mobile и MyMemory, их тайм-ауты и fallback сохранены; API-ключ пользователю не нужен.
- Встроенный версионированный набор коротких игровых выражений версии cod2-smart-v1.0
  позволяет переводить GG/WP/NT/GLHF/AFK/BRB для RU/EN/UK без сети.
- Старые точные игровые выражения и проверенный транслит сохраняются, но опасные
  подстановки в любой текст не применяются принудительно.
- Локальные script hints различают кириллицу, латиницу и отдельные характерные буквы.
  Общая кириллица больше не автоматически объявляется русским языком.
- Намерение (command/question/warning/praise/inform) определяется дешёвой эвристикой.
- Короткий контекст до 4 сообщений того же автора за 8 секунд используется только
  локально для явного случая NS/no-scope. При смене карты буфер очищается.
- После MT проверяется сохранение чисел, HP, A/B, явных отрицаний, знака вопроса,
  @mentions, URL/IP и известных названий оружия. При неудачной нормализации допускается
  один повтор исходного сообщения без предварительного преобразования.
- При провале инвариантов F8 показывает оригинал с предупреждением; F9 не отправляет
  потенциально повреждённый перевод автоматически.
- Общий переключатель **Smart V1** возвращает классический алгоритм F8/F9 мгновенно,
  без переустановки. Переключатель сленга и стили Clear/Natural/Uncensored сохранены.

## Чего пока нет

V1 — лёгкий безопасный semantic frontend, **не обученная LLM**. Неизвестные фразы
обычно всё ещё переводит онлайн MT. Нет автоматического самообучения, embeddings,
модели смешанных языков, offline NMT и отдельных подписанных обновлений базы знаний.
Вычисляемый confidence — не калиброванная вероятность; safe=true означает лишь
прохождение небольшого набора инвариантов, а не гарантированный точный перевод.

Не собран лицензированный корпус реальных сообщений CoD2; оценка качества на
реальных языковых парах пока НЕ проведена. CPU/RAM/p95/FPS на Windows в игре
также ещё не измерены. Запрещено выдавать синтетические проверки за такие измерения.

## Безопасность и приватность

Сохраняется чтение только новых строк console_mp.log, фильтрация сообщений,
F8 overlay, F9 keyboard send и установка/обновление. Никаких DLL-инъекций,
обходов античита и правок памяти игры. В интернет передаётся только одна
отфильтрованная чат-реплика, а не лог целиком, ник отправителя или историю
сообщений. Никакая телеметрия или AI API не добавляются.

## Проверки и критерии выпуска

В рабочем каталоге с установленными зависимостями:

    python -m unittest discover -s tests -v
    python tools/smart_quality_check.py
    python -m compileall -q smart_engine.py app.py outgoing_chat.py translation_fallback.py

Offline quality check: 32 синтетических примера с подставным ответом MT,
каждый помечен SYNTHETIC. Измеряется только выполнение защитных правил.
Желательный результат: все пройдены, unsafe_accepted=0 и valid_rejected=0.

После зелёного Windows RC CI пользователь проверяет в игре:

1. F8: GG, WP, NS, 1hp, rush B, транслит, смешанные языки, ошибки и мат.
2. F9: RU→EN, EN→RU, UK→PL; Enter до окончания перевода; Esc/F9 отменяют.
3. Повреждённый перевод F9 не отправляется; корректный уходит ровно один раз.
4. Smart V1 ON/OFF без перезапуска; сравнить Classic с прошлой v1.17.4.
5. Offline/slow Google/MyMemory fallback и burst сообщений; смену карты.
6. Ники и форматирование, серверы/mod-пути, F8/F9/F10 и оверлей.
7. Измерить CPU/RAM, latency p50/p95 и FPS на старом ПК.

Пока реальный ручной playtest не пройден, PR остаётся draft и
релиз v1.18.0 НЕ выпускается. При регрессии включить Classic и
зафиксировать текст примера, язык, ожидаемый смысл и фактический результат
без публикации персональных данных.
