# CoD2 Chat Translator — V1.11.1

Автопереводчик чата Call of Duty 2 Multiplayer без DLL-инъекции. Читает только строки чата из `console_mp.log`, автоматически определяет исходный язык, переводит на выбранный язык и показывает результат в click-through оверлее поверх игры.

### Удачное положение теперь используется по умолчанию

На чистой установке оверлей стартует **слева, немного выше середины экрана** — в позиции, которая оказалась удобной в реальной игре. Позиция рассчитывается относительно разрешения монитора, а не жёстко под один экран.

Стартовый вид новой установки:

- шрифт: **10**;
- фон: **15%**;
- фон виден **только во время сообщения**;
- компактная подложка только под текстом;
- **2 сообщения**;
- показ около **10 секунд**;
- плавное появление/исчезновение.

Если положение не подходит, нажми **«Настроить оверлей»** и перетащи его. Кнопка **«Стандартное место»** в любой момент возвращает рекомендуемую позицию.

> При обновлении поверх старой версии существующий `config.json` не затирается, поэтому уже настроенное пользователем положение остаётся прежним.

### Три стиля игрового сленга

В строке **«Умный чат»** появился выбор стиля:

- **Понятный** — расшифровывает сокращения максимально ясно: `noob → неопытный игрок`, `wtf → что за фигня`;
- **Живой** — вариант по умолчанию: короткий взрослый игровой язык без канцелярщины: `noob → нуб`, `owned → размотал`, `clutch → затащил`, `bro → братан`, `wtf → какого хрена`;
- **Без цензуры** — сохраняет грубость оригинального сообщения, если она уже есть в исходнике. Программа **не добавляет мат сама**, когда исходная фраза нейтральная.

Примеры:

| Исходник | Понятный | Живой | Без цензуры |
|---|---|---|---|
| `gg` | хорошая игра | хорошая игра | хорошая игра |
| `wp` | хорошо сыграно | хорошо сыграно | хорошо сыграно |
| `wtf` | что за фигня | какого хрена | что за хуйня |
| `noob` | неопытный игрок | нуб | нуб |
| `owned` | полностью переигран | размотал | размотал |
| `camper` | кемпер | кемпер | крыса |
| `stfu` | замолчи | заткнись | заткнись нахуй |

Словарь также понимает `gg wp`, `glhf`, `ns`, `nt`, `afk`, `brb`, `ty`, `thx`, `np`, `hs`, `tk`, `ff`, `nade`, `smoke`, `rush a/b`, `go mid`, `spawncamp`, `arty`, `airstrike`, `ks`, `votekick`, `packet loss`, `fps drop`, `tdm/dm/ctf/sd/hq` и другие CoD/FPS-выражения.

Для длинных фраз сокращения сначала раскрываются, затем вся строка переводится обычным переводчиком. Например `gg bro` превращается в понятную фразу до отправки на перевод.

## Перевод между языками

Исходный язык выбирается автоматически. Пользователь задаёт только язык назначения. Поэтому один и тот же архив можно дать игроку, который не знает русский: он выбирает **English**, и русские сообщения переводятся на английский. Аналогично польский можно переводить на немецкий, английский на украинский и т. д.

В интерфейсе есть большой список языков и кнопка **«Другой…»** для дополнительного кода языка.

## Оверлей

- click-through после фиксации — мышь проходит сквозь него;
- `F8` — скрыть/показать оверлей, перевод при этом продолжает работать;
- размер текста 7–20;
- фон 0–90%;
- фон только во время сообщений;
- компактная подложка по фактическому размеру текста;
- усиленная чёрная обводка букв для светлых карт;
- 1–3 сообщения;
- TTL 5–20 секунд;
- плавное появление/исчезновение;
- пресеты «Только текст», «Минимальный», «Читаемый»;
- кнопка «Стандартное место»;
- ручное перетаскивание и изменение размера в режиме настройки.

## Настройки

Все настройки установленной версии сохраняются автоматически в `%APPDATA%\CoD2ChatTranslator\config.json`: язык, позиция, размер окна, шрифт, фон, TTL, число сообщений, стиль сленга и путь к логу.

Предыдущая версия настроек дополнительно хранится в `config.backup.json`. В релизный ZIP `config.json` **не включается**, поэтому обновление поверх старой папки не стирает пользовательские настройки.

## Запуск

1. В CoD2 включи логирование: `/seta logfile 2`.
2. Установи `CoD2ChatTranslator_Setup_v1.11.1.exe` и запусти программу с ярлыка.
3. Если путь к `console_mp.log` не найден автоматически — выбери его вручную.
4. При необходимости нажми `CoD2 → поверх` для borderless-режима.
5. Выбери язык назначения и стиль сленга.

## Приватность

`console_mp.log` может содержать служебные параметры и пароли сервера. Не публикуй полный лог. Программа фильтрует его локально: в сервис перевода отправляется только текст уже распознанной строки чата, а не весь файл.
