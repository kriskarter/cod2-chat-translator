# COD 2 Chat Translator

**Переводчик чата для Call of Duty 2 Multiplayer, который работает прямо во время игры.**

Сделал эту штуку по простой причине: в CoD2 до сих пор играют люди из разных стран, и на одном сервере легко встретить английский, польский, русский, украинский или немецкий вперемешку. Постоянно сворачивать игру и копировать сообщения в переводчик — такое себе.

Здесь всё проще: программа читает чат из обычного лога CoD2, переводит новые сообщения и показывает перевод небольшим оверлеем поверх игры.

Никаких DLL-инъекций и вмешательства в память игры.

## Как это работает

CoD2 умеет писать консоль в файл `console_mp.log`. Переводчик следит за новыми строками в этом файле и сам отделяет настоящий чат от служебного мусора: загрузки карт, dvar-параметров, путей к файлам и прочего.

Когда появляется сообщение игрока:

1. программа забирает только текст чата;
2. сама определяет, на каком языке он написан;
3. переводит его на выбранный тобой язык;
4. на несколько секунд выводит перевод в оверлей.

При желании рядом можно показывать и оригинал.

## Первый запуск

Ставишь программу обычным `Setup.exe` и запускаешь с ярлыка.

Если логирование в CoD2 ещё выключено, один раз введи в игровой консоли:

```text
/seta logfile 2
```

При запуске программа попробует найти `console_mp.log` сама. Если CoD2 лежит в нестандартной папке или используется отдельная папка мода, просто нажми **«Выбрать…»** и укажи нужный `console_mp.log`.

Дальше выбираешь язык, на который хочешь переводить чат, и можно играть.

> Для самого перевода нужен интернет: текст сообщения отправляется в онлайн-сервис перевода.

## Оверлей

Оверлей можно настроить под себя и потом вообще о нём не думать.

Меняются размер текста, прозрачность фона, количество сообщений и время показа. Есть готовые варианты вроде **«Только текст»**, **«Минимальный»** и **«Читаемый»**.

Через **«Настроить оверлей»** его можно перетащить и изменить размер. После фиксации мышь проходит сквозь окно, поэтому оно не мешает игре.

`F8` — быстро скрыть или вернуть оверлей. Сам перевод при этом не останавливается.

## Игровой сленг

С обычным переводчиком короткий игровой чат иногда превращается в ерунду. Классический пример — `camp`, который легко получить как «лагерь», хотя игрок явно говорит про кемпера.

Поэтому перед переводом программа отдельно разбирает частый FPS-сленг: `gg`, `wp`, `ns`, `nt`, `afk`, `brb`, `tk`, `nade`, `smoke`, `rush`, `camp`, `spawncamp`, `votekick`, `fps drop` и другие выражения.

Есть три режима:

- **Понятный** — если хочется просто понять смысл без игрового жаргона.
- **Живой** — короткие формулировки, ближе к тому, как реально пишут в игре.
- **Без цензуры** — не сглаживает грубость, если она уже есть в оригинале. Нейтральную фразу программа сама матерной не делает.

Например `stop camp` в игровом контексте понимается как просьба перестать кемперить, а не как предложение «остановить лагерь».

## Языки

Исходный язык выбирать не нужно — он определяется автоматически.

Ты выбираешь только язык, на котором хочешь видеть перевод. Поэтому русские сообщения можно переводить на английский, английские на украинский, польские на немецкий и так далее.

## Настройки

Программа запоминает положение оверлея, размер текста, фон, язык, стиль сленга и выбранный лог.

Настройки установленной версии лежат отдельно от файлов программы:

```text
%APPDATA%\CoD2ChatTranslator
```

Поэтому обычное обновление не должно сбрасывать уже настроенный оверлей.

## Обновления

Проверить новую версию можно прямо из программы.

Обновления берутся из GitHub Releases. Перед установкой пакет проверяется по SHA256, а при ошибке обновлятор старается вернуть предыдущие файлы.

## Приватность

Здесь есть один важный момент.

`console_mp.log` — это не только чат. В нём могут оказаться служебные параметры сервера и даже пароли.

**Не выкладывай полный `console_mp.log` в открытый доступ.**

Переводчик фильтрует файл локально. В сервис перевода уходит только текст уже распознанного сообщения чата, а не весь лог целиком.

## Если хочешь собрать сам

Для локальной Windows-сборки нужны Python 3.12+ и Inno Setup.

Запусти:

```bat
BUILD_RELEASE.bat
```

Та же сборка автоматически проверяется на Windows через GitHub Actions.
