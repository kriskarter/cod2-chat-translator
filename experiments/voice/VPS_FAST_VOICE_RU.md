# VPS Fast Voice · эксперимент для CoD2 (без изменения стабильной программы)

## Проверочный экземпляр на VPS · 13 ноября 2026

После Linux-протокольных тестов на Contabo запущен **отдельный**
`cod2-fast-voice-experiment.service`, а не стабильная программа.
Слушает только `127.0.0.1:8765`, пользователь `cod2voice`, модель `tiny`,
`CPUQuota=100%`, `MemoryMax=1800M`, `Nice=15`.
Сервис **не включён в автозапуск** после перезагрузки VPS.
Основные сервисы TSA/Svitlo/VoidCore и прокси не затрагивались.

Проверено: 27 protocol/quality tests на VPS — PASS; real inference
и HTTP end-to-end на синтезированном английском голосе ~1.76 сек:
- без cgroup-лимита: 1.7–2.6 сек на локальном эксперименте VPS;
- с лимитами постоянного тестового сервиса: ASR 3.333 сек,
  HTTP localhost round-trip 3.339 сек;
- память процесса сервиса после запроса около 246 МБ;
- точный текст распознавания: `Easy, go be now.` вместо `Easy! Go B now!`.

Числа **не сравнимы напрямую** с прежними 20.5 сек на ноутбуке,
пока не проверим один и тот же реальный игровой аудиофрагмент и
не измерим задержку SSH/Интернета до твоего компьютера.

Управление из терминала VPS:
```bash
sudo systemctl status cod2-fast-voice-experiment.service
sudo systemctl start cod2-fast-voice-experiment.service
sudo systemctl stop cod2-fast-voice-experiment.service
sudo sh -c "grep '^COD2_VOICE_TOKEN=' /etc/cod2-fast-voice-experiment.env"
```

Последняя команда показывает личный токен **только в твоей консоли**.
Не присылай его в чат и не публикуй. Не открывай порт 8765 во внешнем
firewall и не редактируй конфигурацию рабочего nginx для тестирования.

## Назначение

Когда ноутбук обрабатывает короткое слово Whisper tiny за ~20.5 секунды,
опциональный режим VPS Fast Voice переносит только распознавание речи на
выделенный CPU-процесс VPS. Голосовой файл, сбор ID игрока из UDP, overlay,
онлайн-перевод текста и вся работа CoD2 остаются **на компьютере игрока**.

**Статус:** отдельный experimental PR #3; не включать в stable до Windows
playtest и измерений. Клиент по умолчанию всегда работает локально.

### Что передаётся

- Только выбранный кусок incoming CoD2 voice.wav, PCM 8kHz mono s16le
  (до 12 с, не весь файл, не микрофон).
- Только при явном выборе `VPS Fast Voice`, наличии токена и нажатии
  `Слушать игру` / `Проверить запись`.
- В обратную сторону возвращаются текст, язык, диагностические показатели
  сегментов и время вычислений. Сервер **не пишет и не пересылает аудио**.
- Сервер не принимает ник, IP игрока, SteamID, игровые UDP-пакеты или
  данные учётной записи. Ник определяется исключительно локально.

**Пределы доверия:** VPS видит сами голосовые фрагменты в момент обработки.
Временные данные могут существовать в памяти процесса, но не сохраняются на
диск приложением. Сторонние системные журналы, дампы памяти и провайдер
хостинга не охватываются этим обещанием.

## Сетевая безопасность — без открытого UDP/TCP сервиса

Сервер сам слушает **только 127.0.0.1:8765 на VPS**.
Клиент принимает только HTTPS URL; простое HTTP разрешено исключительно
для 127.0.0.1 или localhost, когда подключён **SSH-туннель**. Токен минимум
32 символа, не сохраняется ни в .cfg, ни в логах клиента.

Для первого теста можно открыть **на компьютере с Windows** отдельное
PowerShell-окно с SSH-туннелем (заменить адрес и логин VPS на свои):

```powershell
ssh -N -L 8765:127.0.0.1:8765 user@YOUR_VPS_HOST
```

Для Windows-прототипа затем:

- `Где распознавать` → `VPS Fast Voice`
- `VPS / SSH-туннель` → `http://127.0.0.1:8765`
- `Токен` → личный токен из конфигурации сервера, длина от 32
- `Проверить` → ожидается `VPS Fast Voice доступен`
- `Слушать игру` → серверное распознавание; если туннель упадёт, локальный
  Whisper/Vosk запускается автоматически; сетевые повторы временно
  приостанавливаются, чтобы не тратить время на каждую реплику.

**Не пересылайте** токен, конфиг с паролями, полный лог игры или файл с
токеном третьим лицам. Не направляйте TCP/8765 на публичный IP.

## Установка на VPS — после проверок и только в изоляции

На Ubuntu 24.04, с отдельной непривилегированной учётной записью, отдельным
виртуальным окружением Python 3.12. Не выполняйте pip от системного root.

Поставить `faster-whisper==1.2.1`, `numpy` и их зависимости в независимый
venv. В тестовой версии серверу необходимы `voice_vps_server.py` и модель
`Systran/faster-whisper-tiny`; модель скачивается при первом запуске и
остаётся в отдельном cache VPS. Запуск:

```bash
export COD2_VOICE_TOKEN='YOUR_32_PLUS_CHARACTER_RANDOM_TOKEN'
python voice_vps_server.py --port 8765 --model tiny --threads 2
```

`COD2_VOICE_TOKEN` — **случайный секрет**, не пример выше; генерируйте
его локально через `python3 -c 'import secrets; print(secrets.token_urlsafe(48))'`.
Секрет не коммитить в GitHub. В production использовать закрытый файл
окружения с правами 0600, отдельного пользователя и ограничения ресурсов.
Пример ограничений systemd:

```ini
[Service]
User=cod2-voice
WorkingDirectory=/opt/cod2-fast-voice
EnvironmentFile=/etc/cod2-fast-voice.env
ExecStart=/opt/cod2-fast-voice/venv/bin/python /opt/cod2-fast-voice/voice_vps_server.py --port 8765 --model tiny --threads 2
Restart=on-failure
RestartSec=3
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/var/lib/cod2-fast-voice
MemoryMax=1800M
CPUQuota=100%
TasksMax=64
```

Для первой проверки используйте **не постоянный сервис**, а отдельный
временный процесс с `nice`, чтобы не ухудшить работу TSA, Svitlo Hromady
и VoidCore. Постоянный сервис включать только после CPU/latency benchmark
под реальной нагрузкой и проверки влияния на существующие приложения.

## Поведение и ограничения

- Передача отправляется как base64 PCM внутри JSON по защищённому каналу.
- Протокол v1: `GET /healthz` и `POST /v1/asr`, Bearer-токен.
- Один запрос к Whisper одновременно. Следующий при занятости получает
  `HTTP 503`; клиент возвращается на локальный движок.
- Клиент ограничивает время ответа VPS до 7.5 с. При сбое 12 секунд
  повторно не обращается к серверу, а запускает локальный резерв.
- Модель `tiny` автоматически определяет язык. Оценка языка **не является
  уверенностью в правильности текста**. Порог 55% более не отбрасывает
  понятные короткие фразы, например `Easy!`.
- Окончательный перевод текста остаётся отдельным асинхронным шагом:
  если «Переводить (онлайн)» включён, текст может передаваться в Google
  GTX / MyMemory. Если опция выключена, туда ничего не отправляется.
- Если VPS недоступен и запасная модель ещё не загружена на ноутбуке,
  её первая загрузка/загрузка из сети может добавить ожидание.
- Безопасный туннель требует работоспособного SSH. Для автоматической
  настройки без отдельного окна нужен будущий отдельный этап интеграции.

## Приёмочные проверки

1. Все unit-тесты protocol/quality и Windows experimental build GREEN.
2. Проверка теста `Easy!` с confidence ~54.6%: текст остаётся виден,
   может быть помечен как предварительный.
3. Проверка запрета `http://PUBLIC_IP`, ошибочного токена, переполненного
   запроса, перегрузки сервера, отсутствия сети и fallback.
4. Замер *на одной и той же реальной записи* локального и серверного ASR:
   queue, network, server inference, end-to-end (p50/p95), качество текста.
5. Тест реальных голосовых пакетов CoD2 в игре и поведения ников.
6. До измерений скорости и Windows playtest **никакого merge/release**.
