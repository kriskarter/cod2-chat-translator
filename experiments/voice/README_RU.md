# CoD2 Voice Prototype — экспериментальная версия

Независимое приложение для входящего голосового чата Call of Duty 2. **Не является обновлением стабильного CoD2 Chat Translator.**

## Как проверить без Python

1. В GitHub Actions скачай артефакт **CoD2-Voice-Prototype-Windows** из зелёного запуска **Build CoD2 Voice Prototype**.
2. Распакуй ZIP **полностью**, не вынимай только `.exe`.
3. Запусти `CoD2VoicePrototype.exe` в папке `CoD2VoicePrototype`.
4. Для проверки на уже присланном файле выбери **Выбрать → voice(3).wav → Проверить запись**.
5. Для живого теста запусти CoD2 Multiplayer, убедись, что `winvoice_save_voice 1` включён, выбери файл `voice.wav` в каталоге игры и нажми **Слушать игру**. Программа начинает с текущего конца файла — старые разговоры не повторяются.

**Первый запуск Whisper:** программа автоматически скачивает модель `tiny` (десятки мегабайт) в локальную папку пользователя. Для этого один раз нужен интернет; последующее распознавание работает офлайн. Если модель не скачивается, проверь DNS и соединение. `base` точнее, но медленнее и крупнее.

Модель запускается на CPU, поэтому на ноутбуке 2013 года скорость зависит от процессора. Переключи модель на `tiny`, если обработка отстаёт. Язык определяется **для каждой реплики отдельно**. Короткие игровые слова распознаются менее надёжно, чем полноценные фразы.

## Что делает приложение

- Только читает дописываемый CoD2 `voice.wav`: PCM signed 16-bit LE, mono, 8000 Hz, **без RIFF-заголовка**.
- Отслеживает новые байты, сброс и пересоздание файла; хранит текущую позицию чтения.
- Объединяет короткие сетевые пакеты по паузе роста файла (0,85 с), ограничивает длительность (~11 с).
- Делит накопившийся файл на речевые фрагменты по RMS/паузам.
- Преобразует 8 → 16 кГц и вызывает локальный `faster-whisper` (CPU/int8).
- Показывает исходную фразу, язык и при включённой опции онлайн-перевод на выбранный язык.
- Если DNS/переводчики недоступны, распознанный **оригинал сохраняется на экране**.
- Показывает отдельное перемещаемое окно-субтитр и список фраз.
- Никаких DLL-инъекций, чтения памяти, вмешательства в CoD2 или микрофон. Ник говорящего невозможно восстановить из общего `voice.wav`.

## Как включить субтитры ПОВЕРХ CoD2

Окно субтитров видно на рабочем столе, но **эксклюзивный fullscreen DirectX перекрывает обычные окна Windows**. Изменение флага «Поверх всех окон» само по себе не решает это.

1. Запусти CoD2 Multiplayer.
2. Если субтитров внутри игры не видно, в консоли игры (~) введи:
   - `/r_fullscreen 0`
   - `/vid_restart` (это перезапустит видеорежим CoD2).
3. Вернись в окно **CoD2 Voice Prototype** и нажми **«CoD2 → поверх»**. Приложение найдёт окно запущенной игры и превратит **оконный** CoD2 в безрамочное окно на весь монитор (borderless).
4. Галочку **«Перемещать субтитры»** включай только когда хочешь перетащить прямоугольник мышью по экрану. Когда разместишь, сними галочку: субтитры становятся *click-through*, не мешают стрелять/целиться. Флаг **«Оверлей»** включает/выключает видимость.
5. Снова переключись в игру и проверь. При реальном голосе появятся субтитры. Для быстрого теста используй «Проверить запись», но сам файл должен существовать, и Whisper должен успеть его распознать.

**Гарантия:** сквозь эксклюзивный полноэкранный DirectX обычное внешнее окно не показывается. Поэтому кнопка не выполняет «инъекцию поверх DirectX»: сначала нужен оконный режим, затем borderless. Если у Windows/драйвера режим не применился, снова проверь `/r_fullscreen 0` + `/vid_restart`. Проект не меняет конфиг CoD2 самостоятельно.

**Безопасность:** программа не отправляет клавиши в игру, не читает память, не изменяет игровые файлы. Win32-кнопка влияет только на стиль окна уже запущенной игры; при перезапуске CoD2 исходный режим восстановится согласно его конфигурации.

Распознавание **офлайн**, но опция «Переводить (онлайн)» отправляет только распознанный текст в Google GTX либо MyMemory. Если не хочешь отправлять реплики в интернет, отключи галочку.

Сохранение текстового журнала **выключено по умолчанию**. Если включить, журнал `transcripts.jsonl` появится в `%LOCALAPPDATA%\CoD2VoicePrototype\`. Сырой голос никогда не загружается на сервер и не переписывается прототипом.

Это ранний прототип. Не ожидай идеальной синхронизации и распознавания: смешанные голоса, очень короткие слова, шум и низкое качество 8-кГц VoIP могут вызвать ошибки. Модель может быть несовместима с очень старым процессором; это выяснится на реальном ноутбуке.

## Запуск из исходников (для разработки)

Windows + Python 3.12:

```bat
py -3.12 -m venv .voice-venv
.voice-venv\Scripts\python.exe -m pip install -r experiments\voice\requirements.txt
.voice-venv\Scripts\python.exe experiments\voice\voice_studio.py
```

Тесты:

```bat
.voice-venv\Scripts\python.exe -m unittest discover -s experiments\voice\tests -v
```

## Границы интеграции

Этот эксперимент не подключается к производственному оверлею и не меняет `app.py`, F9/F8 или установщик. Встраивание в стабильное приложение возможно только после реального теста записи и живого голоса на Windows.
